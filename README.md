# Carestory Patient Timeline

actuando como experto habilitador en salud, creame una historia clinica digital con los datos que estan en el archivo, con el logo y los colores corporativos.  La historia clinica debe ser confidencial, editable en linea y que se pueda descargar para entregar al paciente.  se deben conservar datos del paciente para ingreso posterior y evolución
